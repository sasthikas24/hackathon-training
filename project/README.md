# Blog & Content Publishing Platform (CMS)

A multi-author content management system with editorial review, scheduled publishing, comment moderation, bookmarks, and reader analytics.

## User Roles
- Admin
- Editor
- Author
- Reader

## Core Features
- Create and save drafts
- Submit posts for review
- Approve or request changes
- Schedule and publish posts
- Browse posts by category and tag
- Moderate comments
- Bookmark posts
- Track post views

## Technology Stack
- Java 21
- Maven
- Spring Boot
- SQL database
- React and TypeScript

## Development
This project is developed incrementally as part of hackathon training.
