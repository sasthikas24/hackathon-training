# Day 8 - Collections Framework Part 2

## Objective
Practice Java Maps, sorting, Comparators, and the equals/hashCode contract.

## Concepts Covered
- HashMap for employee lookup.
- Map.merge() for department frequency counting.
- TreeMap for a sorted department report.
- Comparable for sorting employees by ID.
- Comparator for salary sorting in descending order, followed by name.
- equals() and hashCode() contract demonstration and fix.

## How to Run
```powershell
javac EmployeeDirectory.java
java EmployeeDirectory
```

## Expected Results
- Employee lookup by ID.
- Department frequency counts and sorted department report.
- Employees sorted by ID.
- Top five salaries.
- Demonstration of the missing hashCode() issue and its fix.
